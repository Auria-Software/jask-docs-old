## Créer et partager une Expérience

Depuis la page Expériences du catalogue de Jask, vous pouvez créer une expérience en appuyant sur le bouton “Actions” puis “Créer un scénario”. 

<Steps>
### Déclencheur (premier élément par défaut)

Chaque scénario doit commencer par un [déclencheur](/docs/catalog/experiences/create/start), qui définit comment et quand le parcours sera lancé (à l’ouverture ou de manière périodique). 

### Enchainer les actions

La construction d’un scénario se fait simplement en drag and drop, et à la verticale. 

Les actions se trouvent sur le menu latéral gauche et se répartissent en deux grandes familles : 

- [**Actions utilisateur**](/docs/catalog/experiences/create/human_action) : elles apparaissent directement dans le parcours et sollicitent l’interaction.
- [**Actions internes**](/docs/catalog/experiences/create/internal_action) : elles s’exécutent en arrière-plan pour enrichir ou automatiser le scénario.

Chaque action a une entrée et/ou une sortie, toutes deux illustrées par de petits points. 

- Le point du haut étant l’entrée - il permet de récupérer les informations du bloc précédent pour alimenter le bloc actuel.
- Le point du bas étant la sortie - il permet de récupérer le résultat du bloc actuel pour alimenter le bloc suivant.

Ces points sont à relier avec les points des actions précédentes et/ou suivantes, pour créer votre workflow. 

💡 Vous avez la possibilité de changer l’intitulé de chaque brique, pour une meilleure visibilité. 

### Sauvegarder et déployer le scénario

Une fois votre scénario testé et validé, enregistrez-le grâce au bouton “Déployer” en haut à droite de l’écran. 

Renseignez ensuite les informations demandées :

- Le nom de l'expérience
- La description de l'expérience
- La visibilité de l'expérience
- Le tag de l'expérience pour qu'il apparaisse dans la bonne section dans le catalogue



</Steps>
