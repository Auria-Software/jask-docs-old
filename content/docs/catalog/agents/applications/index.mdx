Les applications ou workflows sont la modélisation de processus métiers en tâches prédéfinies afin de les automatiser.
Les workflows sont créés par les membres de votre organisation et sont utilisables partout dans Jask.
Utilisez les workflows depuis l'accueil de Jask ou depuis la page `Workflows` dans le catalogue de Jask.
Si vous avez les droits nécessaires, vous pouvez créer un workflow depuis la page `Worfklows` dans le catalogue de Jask.
