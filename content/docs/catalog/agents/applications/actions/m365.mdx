# Les briques Microsoft O365

Les actions Microsoft 0365 permettent de créer des intéractions avec votre environnement Microsoft et vos ressources telles que vos emails, vos transcripts de réunions Teams ou votre boîte email (rédaction). Il existe 4 briques :

- Envoyer un email
- Créer un brouillon (Draft)
- Lire mes mails
- Transcripts Teams

### Guide d'utilisation

Cette action vous permet d'envoyer un mail à un ou plusieurs destinataires.

<Callout type="warning">
  Les emails envoyés par cette action le sont depuis l'adresse email du compte
  ayant lancé le workflow.
</Callout>

Pour utiliser cette action, cliquez sur le bouton `+ Ajouter` puis sur `Microsoft 0365` et enfin sur `Envoyer un mail`.
Une fois l'action dans le workflow, vous pouvez entrer l'adresse email du destinataire, le sujet du mail et le contenu du mail - ou bien rendre ces éléments dynamiques grâce aux pins en entrée de la brique.

Exemple d'utilisation pour un email dont le destinataire est statique, et le contenu généré par un prompt.

Cette action vous permet de créer un brouillon de mail dans votre boite mail à partir des entrées de l'action.

## Analyse de document Word

Cette action permet à l'IA de lire le contenu mais également tous les commentaires d'un document Word.

<Callout type="warning">
  Cette action ne peut être utilisée que sur des documents Word.
</Callout>

Pour utiliser cette action, cliquez sur le bouton `+` puis sur `Tâche prédéfinie` et enfin sur `Analyser un document Word`.
Une fois l'action dans le workflow, vous pouvez y attacher le contexte où l'utilisateur déposera son document Word pour que l'app puisse y lire le contenu et les commentaires.

Écrivez vos instructions dans la zone de texte pour guider l'IA à analyser le document Word.
