# Gestion des modèles

Depuis la page `Gestion des Modèles`, vous pouvez administrer les modèles d'IA disponibles sur votre plateforme Jask et en gérer l'accès pour vos utilisateurs.
Jask vous permet de connecter librement vos modèles d’IA, qu’ils proviennent d’Azure, du public ou qu’ils soient fine-tunés sur mesure.

![models](@public/models.png)

<Callout>
  Nous recommandons l’utilisation de modèles Azure, déployés directement au sein
  de votre environnement Azure. Cela garantit un niveau optimal de
  confidentialité, de sécurité et de maîtrise de vos données.
</Callout>

| Fournisseur      | Description                                               |
| ---------------- | --------------------------------------------------------- |
| **Azure OpenAI** | Modèles OpenAI déployés sur Azure (GPT-4o, etc.)          |
| **AI Foundry**   | Autres modèles Azure (Mistral, Claude, Llama, etc.)       |
| **Anthropic**    | Modèles Claude via l'API Anthropic directe                |
| **OpenAI**       | Modèles GPT via l'API OpenAI directe                      |
| **Mistral AI**   | Modèles Mistral via l'API Mistral directe                 |
| **Groq**         | Inférence rapide via l'API Groq                           |
| **Other**        | Tout autre fournisseur compatible avec un endpoint custom |

## Azure OpenAI & AI Foundry

L’ajout d’un modèle Azure dans Jask se fait en trois grandes étapes :

1. **Déployer un modèle** chez le fournisseur Azure.
2. **Récupérer les informations du modèle** depuis le fournisseur.
3. **Enregistrer ce modèle dans Jask** depuis la page Gestion des modèles.

<Callout type="warning">
  Le changement fréquent des API Azure OpenAI et Azure Foundry peut entraîner
  des problèmes d'ajout de modèles d'IA dans Jask. Veuillez contacter l'équipe
  Jask si vous rencontrez des problèmes d'ajout de modèles d'IA.
</Callout>

<Steps>

#### Déployer un modèle

Rendez-vous sur la page [déploiement sur Azure Foundry](https://ai.azure.com/foundryProject/overview) pour deployer un modèle Azure OpenAI. Cliquez sur le bouton `+ Déployer un modèle` puis sélectionnez `Déployer un modèle de base`.

{/* ![azure_foundry](@public/settings/ai_models/foundry.png) */}

Cherchez un modèle d'IA que vous souhaitez déployer puis cliquez sur le bouton `Confirmer` pour déployer le modèle d'IA.

{/* ![model](@public/settings/ai_models/model.png) */}

Vous pouvez ensuite augmenter les quotas (tokens par minutes du modèle d'IA) si nécessaire dans la section détails du déploiement. Enfin cliquez sur le bouton `Déployer` pour confirmer le déploiement.

{/* ![quotas](@public/settings/ai_models/quotas.png) */}

#### Récupérer les informations

Cliquez ensuite sur le modèle que vous venez de déployer apparaissant à l'écran pour voir les détails du modèle.

Récupérez les informations suivantes :

1. **`URI Cible`**
2. **`Clé`** d'authentification
3. Nom du modèle (ex. `gpt-4o`)

{/* ![model](@public/settings/ai_models/openai-version.png) */}

#### Enregistrer le modèle sur Jask

1. Ouvrez **Réglages → Gestion des modèles**.
2. Cliquez sur **`+`**.
3. Sélectionnez **`Azure OpenAI`** ou **`Azure AI Foundry`** comme fournisseur.
4. Renseignez les champs du formulaire selon votre fournisseur :

![add_model_providers](@public/settings/ai_models/add-model-providers.png)

| Champ            | Description                                                                          | Statut       |
| ---------------- | ------------------------------------------------------------------------------------ | ------------ |
| **Display name** | Alias visible dans la liste des modèles (ex. `Mon Mistral`, `GPT Prod`)              | Requis       |
| **Endpoint**     | URL de l'API du modèle — obligatoire pour Azure OpenAI et "Other"                    | Conditionnel |
| **Model name**   | Identifiant technique du modèle (ex. `gpt-4o`, `mistral-medium-latest`)              | Requis       |
| **API Key**      | Clé secrète fournie par le fournisseur. Masquée par défaut (icône œil pour afficher) | Requis       |

<Callout type="info">
  **Pré-remplissage automatique pour Azure OpenAI** : lorsque vous sélectionnez
  le fournisseur **Azure OpenAI**, les champs **API Version** et **Model name**
  sont automatiquement pré-remplis avec les valeurs par défaut
  (`2024-12-01-preview` et `gpt-4o`). Vous pouvez les modifier si nécessaire
  pour correspondre exactement aux informations récupérées à l'étape 2.
</Callout>

5. Dépliez la section **`Advanced settings`** si vous devez ajuster les paramètres suivants :

| Paramètre                 | Description                               | Valeur par défaut    |
| ------------------------- | ----------------------------------------- | -------------------- |
| **API Version**           | Version de l'API utilisée pour les appels | `2024-12-01-preview` |
| **Authentication method** | Méthode d'authentification des requêtes   | `Bearer Token`       |

![add_model_advanced](@public/settings/ai_models/add-model-advanced.png)

<Callout type="info">
  Pour la plupart des fournisseurs, les valeurs par défaut conviennent.
  Modifiez-les uniquement si votre fournisseur l'exige explicitement.
</Callout>

6. Cliquez sur **`Test de connexion`** pour vérifier que le modèle est bien accessible.

![add_model_success](@public/settings/ai_models/add-model-success.png)

En cas de succès, un bandeau vert s'affiche en bas de la fenêtre :

> ✅ **Connection successful — you can add the model**

<Callout type="warning">
  En cas d'échec du test, vérifiez : la **clé API**, le **nom du modèle** et
  l'**endpoint**. Assurez-vous également que la **version d'API** correspond
  bien à celle indiquée dans Azure.
</Callout>

7. Cliquez sur **`Add`** pour finaliser l'ajout du modèle.

![add_model_final](@public/settings/ai_models/add-model-final.png)

Une fenêtre de confirmation s'affiche indiquant que le modèle a bien été ajouté, avec son nom et le fournisseur via lequel il est disponible pour tous les utilisateurs du workspace.

![add_model_confirmed](@public/settings/ai_models/add-model-confirmed.png)

Depuis cet écran, vous pouvez :

- Cliquer sur **`Add another`** pour ajouter un nouveau modèle sans fermer la fenêtre.
- Cliquer sur **`Close`** pour fermer la fenêtre et revenir à la liste des modèles.

Après l'ajout, cliquez sur le modèle pour accéder à ses paramètres, gérer les accès utilisateurs, le rendre disponible par défaut ou le supprimer.

<Callout type="info">
  Quand vous partagez un modèle d'IA avec un utilisateur, celui-ci aura accès à
  ce choix de modèle d'IA dans toutes les applications et assistants qu'il
  pourra créer.
</Callout>

{/* ![ai_models](@public/settings/model-update.png) */}

</Steps>
