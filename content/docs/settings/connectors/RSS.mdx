# RSS

![rss](@public/rss/rss.png)

## Objectif du connecteur

Le connecteur RSS (Really Simple Syndication) permet à **JASK** d’ingérer, surveiller et mettre à jour en continu des flux d’actualités provenant de sites web externes.

Contrairement aux connecteurs statiques (fichiers ou scraping ponctuel), le connecteur RSS est conçu pour répondre à des besoins de veille dynamique :

- **Veille continue** : S’abonner à des flux mis à jour régulièrement (actualités, blogs, alertes, communiqués).
- **Découverte intelligente** : Identifier automatiquement les flux RSS disponibles à partir d’une page web ou via l’exploration de sa navigation.
- **Filtrage ciblé** : Sélectionner uniquement les articles pertinents grâce aux tags, aux dates ou à une sélection manuelle.
- **Données enrichies** : Extraire le contenu des articles ainsi que leurs métadonnées (auteur, date de publication, tags, etc.).

## Prérequis

- Disposer d’une URL de flux RSS valide ou d’un site web à explorer
- Avoir un compte administrateur JASK

## Guide de connexion RSS

<Steps>

### Étape 1 : Accéder aux sources de données

Depuis l’interface JASK, ouvrez le menu latéral gauche, cliquez sur **Sources de données**, puis sur le bouton **+ Ajouter une source de données**.

### Étape 2 : Sélectionner le connecteur RSS

Renseignez les informations suivantes :

- **Nom** : Nom de la source (ex. : *Flux Tech*)
- **Connecteur** : Sélectionnez `RSS` dans la liste des connecteurs disponibles
- **Visibilité** : Définissez si la source est privée ou partagée avec les autres utilisateurs
- **Description** : (Optionnel) Description courte du flux

![source de données](@public/rss/info.png)

### Étape 3.1 : Découverte des flux RSS

Le connecteur JASK peut détecter automatiquement les flux RSS associés à l’URL fournie, ou vous pouvez saisir directement une URL de flux.

Paramètres à renseigner :

- **URL(s) cible(s)** : URL du flux RSS ou du site web à analyser (ex. : `lemonde.fr`)
- **Stratégie de découverte** : Lancez la recherche automatique des flux RSS disponibles
- **Type de flux** : Sélectionnez le ou les flux RSS détectés

### Étape 3.2 : Découverte et filtrage des articles

Cliquez sur **Parcourir les articles**.  
Une fois les flux sélectionnés, les articles correspondants s’affichent dans le panneau de droite.

- Les **tags disponibles** s’affichent lorsqu’ils existent
- Vous pouvez sélectionner un ou plusieurs tags pour filtrer les articles
- Tous les flux ne fournissent pas forcément de tags
- La liste des articles se met à jour automatiquement après chaque filtrage

**Suivez les étapes numérotées de 1 à 6 comme indiqué dans la capture ci-dessous.**

![connectivité](@public/rss/connectivite.png)

### Étape 4 : Paramétrer l’indexation

Choisissez la fréquence d’indexation des articles :

- Toutes les 30 minutes
- Toutes les heures
- Une fois par jour
- Etc.

![indexation](@public/rss/indexation.png)

### Étape 5 : Enregistrer et lancer l’indexation

Cliquez sur **Revoir et créer** pour valider la configuration de la source.

### Indexer la source manuellement

<Callout type="info">
L’indexation se lance automatiquement selon la fréquence définie à l’étape 4.
Il est également possible de déclencher une indexation manuelle.
</Callout>

Pour utiliser immédiatement la source de données :

1. Cliquez sur les **trois points** à droite de la source
2. Sélectionnez **Scanner**
3. Rafraîchissez la liste avec le bouton prévu si l’opération prend du temps
4. Cliquez sur **Indexer** pour lancer l’indexation manuelle

![index](@public/rss/index.png)

</Steps>
