# Connecteur BigQuery


![BigQuery](@public/bigquery/bigquery.png)

## Prérequis

- Un compte administrateur BigQuery
- Un compte administrateur Jask

## Guide pour connecter BigQuery

<Steps>

### Etape 1 : Créer un compte de service Google Cloud

Rendez vous sur la page web [Compte de service](https://console.cloud.google.com/iam-admin/serviceaccounts) depuis le portail Google Cloud Plateforme.

Cliquez sur le bouton `+ Créer un compte de service` au centre de l'écran.


![Notion Integration](@public/bigquery/new.png)

Entrez le nom du compte de service `Jask` puis cliquez sur le bouton `Créer et continuer` pour passer à l'étape suivante.

![Notion Integration](@public/bigquery/info.png)

### Etape 2 : Donner les permissions à Jask pour accéder à BigQuery

Donnez les deux droits suivants à Jask :
- `BigQuery Data Viewer` : permet à Jask de lire les données dans BigQuery
- `BigQuery Job User` : permet à Jask de lancer des requêtes SQL dans BigQuery

<Callout type="info">
  Ces permissions permettent à Jask d'executer seulement des requêtes SQL de lecture (Les requêtes SQL modifiant des données ne sont pas autorisées). Vous pouvez changer les permissions à tout moment.
</Callout>

![Notion Integration](@public/bigquery/permissions.png)

Cliquez sur `Continuer` pour passer à la dernière étape de création du compte de service.


### Etape 3 : Créer la clé du compte de service

Rendez vous sur la page de configuration du compte de service puis dans l'onglet `clés` et créer une nouvelle clé `JSON`.

![bigquery key](@public/bigquery/keys.png)

<Callout type="warning">
  Vous devez télécharger la clé en format JSON.
</Callout>

![bigquery key](@public/bigquery/download.png)
