# Les déploiements API et Teams

Depuis les réglages, allez sur la page `Déploiements`, vous pouvez gérer les déploiements API et Teams de vos agents et applications disponibles dans votre organisation.

![deployement](@public/settings/deploy.png)

## API KEY pour les applications externes

Si vous voulez pouvoir appeler vos agents et applications via l'API, vous devez d'abord créer un déploiement API pour avoir des clés d'accès.

Commencez par cliquer sur le bouton `+` pour ajouter un déploiement. Donnez un nom à votre déploiement, sélectionnez l'agent ou l'application à déployer et choisissez le type de votre déploiement (Web (API) ou Microsoft Teams).

![deployement](@public/settings/deploy-add.png)

Une fois le déploiement créé, vous devez éditer le déploiement pour configurer les clés d'accès.

![deployement](@public/settings/deploy-update.png)

Vous pouvez créer une clé d'accès en cliquant sur le bouton `Ajouter` pour créer une clé d'accès.

## Deployer un agent dans Microsoft Teams

### Prérequis :

- Etre administrateur de Jask
- Etre administrateur de Microsoft Teams
- Etre administrateur de Microsoft Entra & Azure

### Étapes :

<Steps>

### Etape 1 : Créer un secret de connexion pour JaskSSO

Si ce n'est pas déjà fait, créer un secret de type 'Connexion O365' pour l'app registration JaskSSO.

<Callout type="warning">
  Le type de connexion 'Sharepoint' est obsolète et ne fonctionne pas avec les
  déploiement dans Microsoft Teams.
</Callout>

![Jask Secret Management](@public/settings/deploy/secret.png)

### Etape 2 : Créer une ressource bot dans Azure

Rendez vous dans le groupe de ressources et créer une ressource bot dans Azure.

![Azure Bot](@public/settings/deploy/rg.png)

![Azure Bot](@public/settings/deploy/add_bot.png)

Configurer la ressource bot dans Azure.

![Microsoft Teams App](@public/settings/deploy/add_bot_2.png)

Une fois la ressource bot créee, rendez vous sur la page de configuration dans le menu gauche de la ressource bot.

1. Ajouter l'url suivante dans le champs `Messaging endpoint` :

```note filename="Messaging endpoint"
{your_jask_backend_url}/external/channel/messages
```

Pour trouver l'url de votre backend Jask, rendez vous sur la ressource webapp `api-jask` dans Azure et chercher le point de terminaison pour récupérer l'url de votre backend Jask.

2. Ajouter un OAuth connection setting avec les informations suivantes :

- **Name** : both-oauth
- **Service Provider** : Azure Active Directory v2

Pour les **Client Id**, **Client Secret** et **Tenant Id**, vous pouvez les trouver dans votre app registration JaskSSO.

Ajouter le **Scope** :

```note filename="Scope"
User.Read
```

![Microsoft Teams App](@public/settings/deploy/configuration.png)

Rendez vous ensuite sur la page `Channels` dans le menu gauche de la ressource bot et ajouter Teams.

![Microsoft Teams App](@public/settings/deploy/add_teams.png)

### Etape 3 : Récupérer les informations du Bot

Allez dans Microsoft Entra et rendez vous sur l'app registration portant le nom de votre ressource bot dans Azure.

Récupérer les informations suivantes :

- **Application (client) id**
- **Application (secret) id**

![Microsoft Teams App](@public/settings/deploy/key.png)

### Etape 4 : Configurer le déploiement dans Jask

Allez dans Jask et rendez vous sur la page `Déploiements`.

Cliquez sur le bouton `+` pour ajouter un déploiement.

Renseignez les informations suivantes :

- **Nom** : Nom du déploiement
- **Application configurée** : choisissez l'agent que vous voulez déployer dans Microsoft Teams
- **Connexion** : choisissez le secret JaskSSO pour l'authentification
- **Bot Id** : Application (client) id de la ressource bot dans Azure récupéré à l'étape 3
- **Bot Secret** : Bot Secret de la ressource bot dans Azure récupéré à l'étape 3
- **Nom dans Teams** : Nom du bot dans Microsoft Teams
- **Short Description** : Description du bot dans Microsoft Teams
- **Long Description** : Longue description du bot dans Microsoft Teams

Cliquez sur le bouton `Valider` pour créer le déploiement.

![Microsoft Teams App](@public/settings/deploy/info_jask.png)

Enfin téléchargez le fichier .zip pour l'installer dans Microsoft Teams.

### Etape 5 : Installer le bot dans Microsoft Teams

Allez dans Microsoft Teams et rendez vous sur la page `Apps`.

Cliquez sur le bouton `+` pour ajouter une app.

![Microsoft Teams App](@public/settings/deploy/zip_teams.png)

Sélectionnez le fichier .zip téléchargé à l'étape 4.

![Microsoft Teams App](@public/settings/deploy/zip_teams_2.png)

Cliquez sur le bouton `Valider` pour installer le bot.

Enfin vous pouvez tester le bot dans Microsoft Teams.

![Microsoft Teams App](@public/settings/deploy/sign.png)

Cliquez sur le bouton `Sign in` pour vous connecter à Microsoft Teams.

![Microsoft Teams App](@public/settings/deploy/answer.png)

Si tout est correct, vous devriez voir la réponse du bot dans Microsoft Teams.

</Steps>
