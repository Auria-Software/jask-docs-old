## Les workflows custom

Créés par vous ou votre organisation, ces workflows permettent de réaliser une série de tâches spécifiques de manière automatisée selon la configuration qui a été définie.
Vous pouvez sélectionner les workflows via la commande @ ou en cherchant dans le catalogue. Et l'exécuter directement depuis la page d'accueil.

### Les workflows natifs (Microsoft)

Ils sont présents par défaut sur votre environnement et permettent d'intéragir avec des ressources Microsoft (emails, transcripts, sharepoints, MS Graph...).

## Interroger vos bases de données

Recherchez des informations dans les bases de connaissance de votre organisation.
L'IA va générer une réponse en fonction de votre requête en se basant sur les bases de données sélectionées.
Vous pouvez **sélectionner une ou plusieurs sources de données** que vous souhaitez interroger avec votre requête en utilisant la commande / puis en tapant le nom de la source

[Voir plus](settings/agentia/applications/intro)

## Enchaîner les interactions

Depuis l'accueil, vous pouvez enchaîner plusieurs services présentés précédemment. Cela vous permet de poursuivre, d'approfondir ou de challenger les résultats fournis par l'IA
Par exemple, vous pouvez :

- **Exécuter** un workflows
- **Rebondir sur le résultat du worfklow** avec un agent pour approfondir
