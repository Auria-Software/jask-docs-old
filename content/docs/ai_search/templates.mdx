# Modèles de documents

Les modèles de documents sont des templates prédéfinis dans lesquels certains champs sont identifiés comme dynamiques. Grâce à l'IA, vous pouvez générer automatiquement des documents personnalisés en indiquant ces informations variables dans votre requête.
Par exemple, vous pouvez créer un modèle de lettre de mise en demeure. Le système générera ensuite le document complet en adaptant les données dynamiques telles que le destinataire, l'adresse ou la date (par exemple).

## Création d'un modèle de document

Afin de créer un nouveau modèle, utilisez le bouton "+" en fin de liste de modèle :

- Définition du titre, catégorie, description et import du document
- Identification et description des éléments à variabiliser, qui seront utilisés et remplacés par l'IA lors de l'utilisation du modèles
- Confirmation de la création du modèle

## Utilisation d'un modèle

Pour générer un document à partir d'un modèle, vous pouvez sélectionner le modèle de document dans la liste, puis saississez les informations variabilisées du modèle que vous souhaitez modifier.
