# Mes bibliothèques

Cet espace de stockage vous est **personnel**.

Dans la limite de 5Go, vous avez la possibilité de gérer des dossiers et des fichiers afin de déposer des ressources particulières qui ne sont pas accessibles au travers des ressources partagées au niveau de l’organisation.

Ces fichiers, bien que personnels, peuvent être accessibles à vos collaborateurs si vous les liez à un Agent que vous leur partagez. Néanmoins, ils ne peuvent pas être modifiés, seulement lus le cas échéant.

![image.png](@public/my_documents/image.png)

## Création et suppression d’un dossier

Vous pouvez créer un dossier en cliquant sur le bouton “+” (à la racine) ou de à la fin de la liste des dossiers. Il suffit de nommer votre nouveau dossier et de valider. Pour naviguer entre dossiers, il vous suffit de double-cliquer sur ce dossier.

Pour éditer ou supprimer un dossier, vous devez le survoler avec votre souris et utiliser une des deux actions.

Attention, la suppression est définitive et supprime également les fichiers ou sous-dossier contenus dans le dossier. Un message de validation sera à cocher pour pouvoir exécuter la suppression.

<Callout>
  Pour naviguer dans les dossiers, il suffit de cliquer deux fois rapidement sur
  un nom de dossier.
</Callout>

## Ajout de fichiers

Pour ajouter un fichier dans un dossier, il vous suffit de sélectionner le bouton “Charger” depuis la barre de boutons en haut à droite. Depuis la fenêtre qui s’ouvre, naviguer sur votre disque pour sélectionner le(s) fichier(s) à importer sur Jask et validez.

<Callout>
  Il est possible de visualiser un fichier en cliquant sur “…” puis
  `Visualiser`.
</Callout>

## A SUPPRIMER ? Actions sur les dossiers et fichiers

En sélectionnant un dossier ou un fichier vous avez accès à l’indexation ou la création d’un assistant sur le ou les éléments sélectionnés.

Une fois sélectionné l’élément choisi, cliquer sur le bouton “Exécuter”.

Les options disponibles sont :

- **Créer un assistant** : Vous avez la possibilité de créer un assistant sur ces éléments. Pour en savoir plus sur la création des assistants, veuillez vous reporter à la page dédiée [Mes assistants](/docs/chats_room/intro)
- **Indexer le contenu** : L’indexation n’est pas automatique. Vous devez la demander spécifiquement.
  ![image.png](@public/my_documents/image%201.png)
  L’indexation prend quelques secondes, le choix de la stratégie peut également impacter le temps d’indexation (Rapide vs Approfondie) ainsi que sur les coûts.
  Laissez faire Jask, il vous préviendra une fois l’indexation terminée.
  ![image.png](@public/my_documents/9d41b17c-ca47-49d9-b342-4da5d16e6b90.png)
  Une fois indexé, l’élément comporte un indicateur.
  ![image.png](@public/my_documents/image%202.png)
- **Supprimer les éléments** : Vous permet de supprimer les éléments sélectionnés.

Le menu “…” au regard de l’élément vous permet également de télécharger l’élément sur votre disque dur.
