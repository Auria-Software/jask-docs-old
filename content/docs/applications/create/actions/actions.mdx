# Les briques d'applications

Les briques sont les éléments que vous allez pouvoir utiliser pour créer vos applications. Ces briques sont agencées les unes par rapport aux autres et constituent les étapes de l'application.
<Callout type="info">
Pour connecter les briques correctement, il faut s'assurer que la sortie d'une brique est compatible avec l'entrée de la brique suivante
</Callout>
