# Traitement de fichiers

Deux actions sont disponibles pour traiter les fichiers :
* Extraction de tableau
* Analyse de fichier(s)

### Guide d'utilisation

Cette action vous permet d'extraire des informations structurées depuis des documents et de les restituer sous forme de tableaux configurables.

![application_file_processing](@public/applications/tab_extraction.png)

Pour utiliser cette action, cliquez sur le bouton `+` puis sur `Traitement de fichiers` et enfin sur `Extraction de tableau`.
Une fois l'action dans le workflow, vous pouvez entrer les colonnes à extraire, sélectionner le modèle LLM utilisé et configurer les paramètres avancés.

### Guide d'utilisation

Cette action vous permet d'analyser ou traiter les documents en entrée (résumé, traduction, restructuration…), en forçant la lecture complète des fichiers si nécessaire.

![application_file_processing](@public/applications/file_analysis.png)

Pour utiliser cette action, cliquez sur le bouton `+` puis sur `Traitement de fichiers` et enfin sur `Analyse de fichier(s)`.
Une fois l'action dans le workflow, vous pouvez sélectionner le type de traitement, configurer les paramètres avancés et entrer les instructions personnalisées.
