# Sources de données

Depuis cette page, vous pouvez voir l'ensemble des sources de données auxquelles vous avez accès dans Jask. Cela permet de vous indiquer quelles ressources pourront être utilisées lors de la création de vos agents par exemples.

Vous pouvez aussi limiter la recherche à certaines bases de connaissances en utilisant le bouton + ou en cliquant sur les bases de connaissances sur la partie basse de l'écran.
