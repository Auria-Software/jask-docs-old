La page d’Accueil de Jask vous permet de consommer les fonctionnalités de Jask de manière simple et intuitive.
Vous y retrouverez `une barre de chat` ainsi que des `accès rapides` à vos ressources et outils préférés.


## Les fonctionnalités

La barre de chat est l'élément central de l'Accueil. Elle vous permet d'interagir avec **les agents, les applications et vos bases de données**. Vous pouvez combiner les différentes fonctionnalités (agents, applications, bases de données) et importer des fichiers à traiter. L'accueil est un véritable point d'entrée vers l'ensemble des services disponibles sur JAsk
L'accueil est conçue pour vous offrir une expérience fluide et intuitive, vous permettant de naviguer facilement entre les différentes fonctionnalités. Chacune d'entre elles possède sa propre page dédiée pour une utilisation plus avancée.
Voici un aperçu des fonctionnalités disponibles :

### 1. Discuter avec des agents

![discuter](@public/accueil/Accueil-Discuter.gif)

Vous pouvez discuter avec [les agents](/docs/chats_room/intro) que vous avez créés ou avec les agents partagés par votre organisation.
Choisissez un agent depuis le + et commencez à poser vos questions.
Si vous sélectionnez plusieurs agents, vous pourrez comparer leurs réponses à une même requête.

#### Discuter sur vos fichiers

![discuter fichier](@public/accueil/Accueil-Discuter-File.gif)

"Discutez" avec un ou plusieurs fichiers spécifiques que vous pouvez glisser et déposer ou importer depuis votre ordinateur.

#### Utiliser un prompt du `Prompt Store`

![discuter prompt](@public/accueil/Accueil-Discuter-PS.gif)

Gagnez du temps en utilisant un prompt déjà sauvegardé dans le `Prompt Store` pour poser une question à l'un de vos agents. Cliquez simplement sur le bouton + puis Prompt Store dans la barre de chat et sélectionnez le prompt que vous souhaitez utiliser.

### 2. Exécuter des applications

Une application est un workflow automatisé d'action. Il existe plusieurs types d'applications :
- Deep Research : Elle permet d'utiliser un mode de réflexion avancé pour traiter la demande de l'utilisateur. L'IA va effectuer une série d'étapes, les unes à la suite des autres afin de fournir le résultat le plus pertinent possible. Cette application peut-être utilisée en plus des autres ressources disponibles pour effectuer des tâches plus avancées et complexes.
- Les applications MS : Elles sont présentes par défaut sur votre environnement et permettent d'intéragir avec des ressources Microsoft (emails, transcripts, sharepoints, MS Graph...). Vous pouvez interroger vos emails, 
- Les applications créées : Créées par vous ou votre organisation, ces applications permettent de réaliser une série de tâches spécifiques de manière automatisée selon la configuration qui a été définie.
Vous pouvez sélectionner une application dans la liste déroulante et l'exécuter directement depuis la page d'accueil.

### 3. Interroger vos bases de données

![rechercher](@public/accueil/Accueil-Rechercher.gif)

Recherchez des informations dans les bases de connaissance de votre organisation.
L'IA va générer une réponse en fonction de votre requête en se basant sur les bases de données sélectionées.
Vous pouvez **sélectionner une ou plusieurs sources de données** que vous souhaitez interroger avec votre requête avec le bouton +

## Enchaîner les intéractions

Depuis l'accueil, vous pouvez enchaîner plusieurs services présentés précedemment. Cela vous permet de poursuivre, d'approfondir ou de challenger les résultats fournis par l'IA
Par exemple, vous pouvez :
- **Exécuter** une application 
- **Rebondir sur le résultat de l'application** avec un agent pour approfondir
