# L'édition 
L'édition d'un agent, d'un workflow ou d'un fichier peut se faire depuis la Chats Room. 
Il est important de noter que cette édition ne peut se faire que si l'utilisateur en a le droit. Ces droits sont définis par l'administrateur. 

## L'édition d'un agent
Il est possible d'éditer un agent depuis la ChatsRoom. Cette modification se fait depuis l'onglet Vue d'ensemble. Dans la partie présentation d'informations générales de l'agent, il est possible de cliquer sur le bouton Editer. 
Dès lors, vous pouvez modifier toutes les fonctionnalités de l'agent : nom, description, instructions, base de connaissance, visibilité...

![edit_agent](@public/chat_rooms/edit_agent.png)

## L'édition d'un workflow
Il est possible de modifier un workflow depuis la partie ChatsRoom. Dans la partie répertoriant les informations générales d'un workflow, cliquez sur le bouton éditer. 
Dès lors, il est possible de modifier certaines informations d'un workflow : nom, description, visibilité. Cependant, il n'est pas possible de modifier la structure et la construction de ce workflow. Cela est possible depuis la section workflow, qui sera détaillée plus tard dans la documentation.

![edit_app](@public/chat_rooms/edit_app.png)

## L'édition d'un fichier 
Il est possible de modifier le contenu d'un dossier de la bibliothèque de fichiers dans la partie Chats Room. 
Depuis l'onglet Vue d'ensemble, il est possible de modifier le contenu du dossier, rajouter des fichiers ou rajouter des sous-dossiers.

![edit_doc](@public/chat_rooms/edit_doc.png)
