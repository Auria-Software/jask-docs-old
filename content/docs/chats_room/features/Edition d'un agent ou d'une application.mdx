# L'édition 
L'édition d'un agent ou d'une application peut se faire depuis la ChatsRoom, respectivement dans la vue "Agents" et "Application"
Il est important de noter que cette édition ne peut se faire que si l'utilisateur en a le droit. Ces droits sont définis par l'administrateur. 

# L'édition d'un agent
Il est possible d'éditer un agent depuis la ChatsRoom, vue "Agents". Cette modification se fait depuis l'onglet Vue d'ensemble. Dans la partie présentation d'informations générales de l'agent, il est possible de cliquer sur le bouton Editer. 
Dès lors, vous pouvez modifier toutes les fonctionnalités de l'agent : nom, description, instruction, base de connaissance, visibilité...

# L'édition d'une application
Il est possible de modifier une application depuis la partie ChatsRoom, vue "Applications". Dans la partie répertoriant les informations générales de l'application, cliquez sur le bouton éditer. 
Dès lors, il est possible de modifier certaines informations de l'application : nom, description, visibilité. Cependant, il n'est pas possible de modifier la structure et la construction de cette application. Cela est possible depuis la section application, qui sera détaillée plus tard dans la documentation.
