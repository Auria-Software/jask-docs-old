# Les Sources de Réponse

Les sources de réponses sont les documents, fichiers ou autres éléments d'information que Jask a utilisé pour répondre à une question. Nous nous efforçons de fournir des réponses précises et pertinentes en nous basant sur les sources de réponse les plus appropriées.

Quand des sources sont utilisées, vous trouverez les mentions de cette source dans la réponse de l'agent pour identifier la source des élements de réponses utilisées pour formuler cette réponse. Passez la souris sur le numéro pour voir le titre et une partie du contenu de la source de réponse.
![grounding](@public/chat_rooms/grounding.png)

<Callout>
  Survolez la mention de la source pour ouvrir l'élément dans l'outil d'origine
  de la source. (SharePoint, Salesforce, Web, etc...). En fonction du format de
  la source utilisée, il s'ouvrira dans un onglet (lien url), un aperçu sera
  affiché (PDF) ou un lien vers la ressource sera ouvert (sharepoint par
  exemple).
</Callout>

Les sources de réponses peuvent être de natures différentes en fonction des connaissances dont l'agent dispose :

- Documents internes
- Fichiers des connecteurs (SharePoint, Salesforce...)
- Informations extraites du web

La liste de toutes les sources de réponse est disponible dans l'onglet "Sources".
![sources](@public/chat_rooms/grounding2.png)
