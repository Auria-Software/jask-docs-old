# La Zone de Chat

La zone de chat est l'endroit où vous pouvez interagir avec vos agents. Vous pouvez poser des questions, demander des clarifications ou explorer différents sujets en temps réel.

![Chat Box](@public/chat_rooms/chatbox.png)

Vous engagez une conversation avec votre agent en tapant le texte de votre question dans la zone de saisie de texte. Une fois complète, la touche “Entrée” envoie la question à votre agent. Vous pouvez également cliquer sur l’icône d’envoi à la toute fin de la zone de saisie.

## Les fonctionnalités de la zone de chat

Plusieurs fonctions sont accessibles depuis la zone de saisie, via le bouton "+" : 

<Steps>
#### Import de fichiers
Importer les fichiers que vous voulez fournir à votre agent en plus de votre requête. Vous pouvez importer des fichiers en cliquant sur le bouton "+" puis "Importer des fichiers" ou en faisant un glisser-déposer de vos fichiers dans la zone de chat.

#### Prompt Store
Vous avez accès au Prompt Store qui vous offre une collection de prompts utiles immédiatement utilisables dans vos conversations. Vous bénéficiez ainsi de la puissance des prompts communs dans votre organisation.

#### Agents
Vous pouvez faire collaborer vos agents ensemble, en ajoutant d'autres agents à votre requête. Dans ce cas, les agents que vous rajoutez répondront à votre requête et vous pourrez rebondir avec l'agent sélectionné.

#### Workflows
Vous pouvez ajouter des workflows de refléxion à votre requête. Cela permet d'exécuter un workflow prédéfini ou un workflow prédéfini (Deep Research, Traduction, Microsoft...)

#### Source de données
Vous pouvez ajouter des sources de données pour fournir un contexte de données supplémentaires à l'agent interrogé.

<Callout>
L'utilisation de plusieurs services est décrite dans l'[accueil](/docs/accueil)

</Steps>
