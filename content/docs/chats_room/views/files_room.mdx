# Les Chats avec Fichiers

L’onglet Fichiers vous permet d’engager une conversation avec de l'IA sur un ou plusieurs fichiers.


![filesroom](@public/chat_rooms/filesroom.gif)

#### Importer des fichiers
Pour créer un nouvel espace de discussion sur des fichiers, vous devez importer ces fichiers dans JAsk. Cliquez sur le bouton (+) et sélectionnez le ou les fichiers que vous souhaitez interroger.

<Callout>
   JAsk se charge de l’indexation des fichiers immédiatement. Cette opération dure quelques secondes en fonction de la taille des fichiers.
</Callout>

![import](@public/chat_rooms/import1.png)

#### Choix du modèle d'IA
Le modèle de LLM par défaut de votre plateforme JAsk est utilisé. Vous pouvez le modifier depuis la vue d'ensemble d'un espace de fichiers, en cliquant sur le bouton éditer.
Depuis ce menu vous pouvez également supprimer cet espace de fichiers.

![edit](@public/chat_rooms/edit.png)

#### Engager une conversation
Vous engagez une conversation avec votre espace de fichiers en tapant votre question dans la zone de chat. Une fois la question complète, appuyez sur la touche “Entrée” pour envoyer votre question ou appuyez sur le bouton "Envoyer".

#### Modifier les fichiers
Vous pouvez à tout moment gérer, renommer ou supprimer des documents dans votre espace de fichiers depuis le bouton "..." dans la colonne de gauche ou depuis l'onglet Fichiers importés de l'espace de fichier.


## Organisation de la page
La page s'organise en plusieurs onglets : 
<Steps>

#### Vue d'ensemble
Sur cette vue d'ensemble, vous pouvez
- Commencer une conversation depuis la barre de chat
- Gérer les fichiers de l'espace depuis le bouton "Éditer"
- Consulter l'historique des dernières conversations avec cet espace de fichiers

#### Fichiers importés
Retrouvez dans cette section tous les fichiers importés sur lesquels se base vos recherches et actions. Vous avez la possibilité d'importer de nouveaux fichiers ou d'en supprimer.
</Steps>
