# Objectif

Depuis la vue ChatsRoom, il est possible d'engager une conversation avec un agent, un workflow ou des fichiers. Il est possible d'avoir plusieurs conversations en parallèle, et de reprendre une conversation là où elle en est.

## Pourquoi avoir des conversations distinctes ?

- **Organisation** : Les conversations distinctes vous permettent de séparer les sujets ou projets. Par exemple, vous pouvez avoir une conversation pour un projet spécifique et une autre pour des questions générales.
- **Contexte** : Chaque conversation conserve le contexte de tous les messages de la conversation, ce qui permet à l'agent de fournir des réponses plus pertinentes basées sur l'historique de la conversation.
- **Gestion** : Vous pouvez facilement retrouver et gérer vos interactions passées en accédant à vos conversations enregistrées.

## Historique de toutes les conversations :

Pour accéder à l’historique des conversations : 

- Soit vous sélectionnez l’agent/workflow/Fichier dans la barre d'affichage. L'historique s'affiche dans le menu déroulant.
- Soit vous avez déjà sélectionné cet agent, et vous cliquez sur l'onglet Conversations. Le numéro indique le nombre de conversations.

## Création

En bas de la liste des agents dans la Chat Room, onglet Agents, vous pouvez créer différents éléments, selon vos droits sur JAsk :

- Section : Les sections permettront d'organiser vos agents dans la liste. Par défaut, les agents sont organisés par ordre de dernière conversation la plus récente.
- Agent IA : Création d'un agent IA [Création d'un agent](/docs/assistants/create)
- Groupe d'agents (BETA) : Création d'un groupe d'agents. Un groupe est défini par son nom, sa description, son mode de fonctionnement, ses membres (agents membres du groupe) et sa visibilité.
  Il existe deux modes principaux de groupe d'agents :
  - Tous les agents du groupe répondent en même temps
  - Les agents du groupe planifient et orchestrent la refléxion par rapport aux agents présents dans le groupe
- Prompt personnalisé : [Création d'un prompt dans le prompt store](/docs/prompts_store)














# Les Chats avec Agents

Depuis l'onglet “Agents” de la Chats Room, vous pouvez engager une discussion avec un agent. Il vous suffit de cliquer sur un agent et immédiatement, la zone principale vous permet d'intéragir avec l'agent.

## Nouvelle Conversation

La barre d’affichage à gauche de la zone vous donne la liste des agents utilisés, avec le nom et la description des agents.

Si un agent est déjà sélectionné, la partie centrale de l'écran présente le détail de cet agent. L'onglet Conversations affiche l'historique de vos conversations et le nombre de conversations que vous avez engagé avec cet agent.
![Conversations](@public/chat_rooms/conversations.gif)

Depuis la barre d'affichage des agents, vous pouvez :

- Créer une `Nouvelle conversation`
- Accéder à vos conversations passées `Mes conversations`
- `Effacer` des conversations.

Cette dernière option supprimme totalement une conversation : attention à son utilisation !



## Agents favoris

Vous avez la possibilité de définir certains agents comme favoris. Cela vous permet de les retrouver plus rapidement.
Vos agents favoris sont regroupés dans la section "Mes favoris" de la barre d'affichage. Pour déplacer un agent dans une section, cliquez sur l'icône "..." puis sur la section cible.
