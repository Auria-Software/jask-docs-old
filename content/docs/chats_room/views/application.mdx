# Vue Application

## Les Chats avec Applications

Depuis l’onglet “Applications” de la Chat Room, vous pouvez donner exécuter des applications. 
Sélectionnez une application dans la liste des applications dans le menu de gauche pour intéragir avec une application

## Organisation de la page
La page s'organise en plusieurs onglets
<Steps>

### Vue d'ensemble
Depuis cette vue, il est possible de : 
- D'exécuter une application en utilisant la barre chat. Cette fonctionnalité est détaillée dans la section [Chat](content/docs/chats_room/features/chat_box.mdx)
- Trouver les paramètres de l'application : nom, description, créateur, section
- Consulter l'historique d'exécution de l'application
- Consulter les utilisateurs ayant le plus utilisé cette application

### Détails
Cette partie détaille le fonctionnement de l'application, sa structure et sa logique. Elle donne du contexte sur les étapes et le but de l'application. 

### Historique
L'historique répertorie toutes les activités liées à cette application. La partie chiffrée correspond au nombre de requêtes effectuées sur cette application.

### A propos du créateur
Cette section vous permet de trouver des informations sur le créateur de l'application et de consulter les autres applications du même auteur.

La barre en-tête de la zone vous donne le nom et la description de l’application en cours d’utilisation.
</Steps>
