# Vue Application

## Les Chats avec Applications

Depuis l’onglet “Applications” de la Chat Room, vous pouvez donner des instructions à avec une application. 
Il vous suffit de cliquer sur une Application et immédiatement, la zone principale vous permet d’interagir avec l’application.

## Organisation de la page
La page s'organise en plusieurs onglets
<Steps>

### Vue d'ensemble
Depuis cette vue, il est possible de : 
- Faire une requête à une application en utilisant la barre chat. Cette fonctionnalité est détaillée dans la section [Chat](content/docs/chats_room/features/chat_box.mdx)
- Trouver les paramètres de l'application : nom, description, créateur, section
- Consulter l'historique de traitement de l'application. Vous y trouverez l'historique des requêtes et résusltats
- Consulter les utilisateurs les plus actifs sur cette application

### Détails
Cette partie détaille le fonctionnement de l'application, sa structure et sa logique. Elle donne un aperçu de la philosophie de construction de l'application, ce qui permet de mieux la comprendre afin de l'utiliser.

### Historique
L'historique répertorie toute les activités liées à cette application. La partie chiffrée correspond au nombre de requêtes effectuées sur cette application.

### A propos du créateur
Cette section vous permet de trouver des informations sur le créateur de l'application et de consulter les autres applications du même auteur.

La barre en-tête de la zone vous donne le nom et la description de l’Application en cours d’utilisation. Le menu à gauche vous permet d’accéder aux options de gestion de résultat de l’Application.
</Steps>
