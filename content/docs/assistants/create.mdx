Depuis la page `Agents IA` du catalogue ou le bouton `Nouveau` de la Chats Room, vous pouvez créer des nouveaux agents.

## Configuration

Plusieurs éléments sont configurables pour créer un agent :

<Steps>
### Étape 1 : Générales

Dans cette étape, vous pouvez renseigner le nom de votre agent, sa description, choisir un avatar et configurer sa visibilité (moi uniquement par défaut, toute mon organisation)

<Callout>
  Un ciblage plus précis de la visibilité de l'agent pourra être défini dans
  l'onglet `Sécurité & Gouvernance`
</Callout>

![assistant_general](@public/assistants/general.png)

### Étape 2 : Connaissances

Dans cette étape, vous pouvez choisir les sources de données que votre agent pourra utiliser quand un utilisateur lui pose une question. Vous pouvez connecter une ou plusieurs sources de données. Vous pouvez choisir entre des sources externes connectées à JAsk (Sharepoint, Web, Salesforce, Notion...) ou bien importer des documents statiques sur l'agent (en utilisant la source **Poste de travail**)

<Callout>
  Si vous ne connectez aucune source de données, votre agent sera un simple
  LLM c'est à dire qu'il répondra uniquement à l'aide des connaissances
  d'entrainement que le modèle sélectionné a reçu.
</Callout>

{/* ![assistant_knowledge](@public/assistants/connaissance.gif) */}

Chaque sources de données est paramétrable en fonction des données que vous voulez fournir à votre agent. Par exemple, si vous connectez un Sharepoint, vous pouvez filtrer les dossiers que vous voulez utiliser.

### Étape 3 : Intelligence

Dans cette étape, vous configurez l'intelligence de votre agent. Vous pouvez configurer :

**Le modèle d'IA**

Sélectionnez le modèle d'IA que votre agent utilisera pour répondre aux questions. Dans la liste déroulante vous voyez les modèles d'IA auxquels vous avez accès.

Ensuite configurez la température du modèle d'IA. La température est un paramètre qui permet de contrôler la créativité de la réponse de l'agent. Plus la température est élevée (proche de 1), plus la réponse est créative et moins elle est conforme à la question posée. Une température élevée signifie que pour une même question, l'agent peut répondre de manière différente à chaque fois.

**Rôle et Modération de cet agent (Prompt System)**

C'est ici que vous allez pouvoir configurer le `Prompt System` de votre agent. Le prompt système est un prompt qui permet de contrôler le comportement de l'agent. Le prompt système vous permet d'ajuster finement le comportement de votre agent.

**Options avancées**

Vous pouvez activer ou desactiver certaines options pour votre agent :

- Cites toujours tes sources (documents, liens, ...) : Cette option permet de référencer les sources de la réponse avec réponse fournie par l'agent. Décochée, les sources utilisées ne seront pas citées par l'agent.
- Suggères des questions liées à la fin : Cette option permet de suggérer des questions liées à la fin de la réponse séléctionnables par l'utilisateur pour continuer la discussion.
- Détailles tes réponses avec la chaine de pensée : Cette option permet de détailler la réponse de l'agent avec la chaine de pensée.
- Informes l'utilisateur lorsque la réponse ne se base pas sur les sources connectées : Cette option permet de prévénir l'utilisateur quand l'agent a utilisé l'entraînement de son modèles sans être allé chercher dans le contenu des sources.
- Utilises la terminologie interne : Cette option permet d'utiliser la terminologie interne de l'entreprise dans les questions de l'utilisateur et les réponses de l'agent. Par exemple : propale -> proposition commerciale.

**Base de connaissances**

Le RAG est un mécanisme qui permet à l'agent de répondre aux questions en utilisant les documents qui lui sont exposés. Vous pouvez configurer le RAG de votre agent afin d'obtenir les résultats les plus pertinents.

- La quantité de documents qui seront récupérés pour répondre à une question: `Dynamique` (mode automatique qui définit la quantité de document à utiliser) ou `Personnalisé` (vous définissez le nombre de documents que l'agent peut récupérer à chaque requête).

- Le degré de diversité des sources récupérées : `Dynamique` (mode automatique qui définit le niveau de diversité à considérer) ou `Minimum de diversités des sources (Top recherches)`(seules les sources les plus pertinentes sont considérées par l'agent) ou `Maximum de diversités des sources (MMR)` (L'agent diversifie au maximum les sources utilisées)

### Étape 4 : Opérations Agentiques

Dans cette étape, vous configurez les opérations agentiques de votre agent. Ce sont les outils a disposition de l'agent, que l'agent peut décider d'utiliser ou non, en fonction de la requête de l'utilisateur.

<Callout type="warning">
  Si vous activez le mode agentique, le **prompt system** de l'agent n'est
  plus pris en compte.
</Callout>

Trois modes agentiques existent :

- **Mode Defaut**

Dans ce mode, l'agent peut utiliser l'ensemble des sources de données et extensions qui lui sont mis à disposition pour répondre au mieux à la question de l'utilisateur.

<Callout>
  Activez des sources de données dans les connaissances de l'agent pour voir
  les actions agentiques possibles de cette source de données.
</Callout>

![super_agent](@public/assistants/agent_default.png)

- **Mode Super Agent**

Dans ce mode, l'agent devient un chef d'équipe et son rôle est de déléguer les demandes des utilisateurs à des agents plus spécialisés.

![super_agent](@public/assistants/super_agent.png)

- **Mode Deep Agent**

Dans ce mode, l'agent planifie chacune des demandes utilisateur en une série de tâches à effectuer puis exécute le plan de manière itérative.
Ce mode est plus adapté pour des questions complexes qui nécessitent une recherche et une réflexion approfondies.

Comme pour l'agent par défaut, vous avez la possibilité d'activer des opérations (sources de données et extensions) que l'agent peut effectuer.

![deep_agent](@public/assistants/deep_agent.png)

<Callout type="warning">
  Le comportement du Deep Agent va être progressivement déprécié en faveur de
  l'application Deep Research que les utilisateurs pourront activer nativement
  quand leur requête demande une analyse et une réflexion plus approfonfie.
</Callout>

### Étape 5 : Sécurité & Gouvernance

Dans cette étape, vous configurez la sécurité et la gouvernance de votre agent.

**Mode de contrôle d'accès aux ressources**

    * **`Délégué à la source`** : le contrôle d'accès aux ressources est géré par la source de données. Par exemple, pour un agent connecté à l'entièreté d'un environnement Sharepoint, si deux utilisateurs n'ayant pas les mêmes droits dans le Sharepoint posent la même question, les réponses seront différentes. En effet, l'agent répondra uniquement en prenant en compte les documents auxquels l'utilisateur posant la question a accès.

    * **`Partage via Jask`** : le contrôle d'accès est géré via Jask. Dans ce cas, les deux utilisateurs auront la même réponse qui se basera sur l'entièreté des documents auxquels l'agent a accès.

**Utilisateurs et Groupes**

Vous pouvez définir plus spécifiquement les utilisateurs et groupes qui auront accès à votre agent.

<Callout type="warning">
  Les utilisateurs indiqués ici, ne seront pris en compte que si le paramètre
  "Tout mon organisation" a été défini dans le premier onglet "Générales"
</Callout>

**Gouvernance**

Vous pouvez décider de limiter la consommation d'un agent par un utilisateur :

- Nombre de requêtes : Limiter le nombre de requêtes qu'un utilisateur peut envoyer à un agent
- Volumétrie de données : Limiter la quantité de données qu'un utilisateur peut consommer auprès d'un agent (Nombre d'octets ou de tokens consommés)

<Callout type="warning">
  Les valeurs d'utilisation par utilisateur ne sont pas réinitialisées
  automatiquement pour le calcul des limites.
</Callout>

![security](@public/assistants/security.png)

### Étape 6 : Expérience utilisateur

- **Message d'accueil** : Définition du message d'accueil affiché par l'agent au démarrage d'une conversation
- **Exemples de demandes** : Définition d'exemples de questions de démarrage pour inspirer les utilisateurs de l'agent
- **Afficher le prompt système** : Permet d'afficher/masquer le prompt système aux consommateurs de l'agent
- **Afficher les sources connectées** : Permet d'afficher/masquer les sources connectées à l'agent aux consommateurs de cet agent
- **Recommandation d'applications** : Permet de sélectionner des applications qui seront mis en valeur lors de l'utilisation de l'agent par les utilisateurs.
  ![ux](@public/assistants/ux.png)

</Steps>
