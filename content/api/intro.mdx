# Introduction à l'API Jask

Bienvenue dans la documentation de l'API Jask. Cette API vous permet d'intégrer des assistants IA conversationnels et des workflows d'automatisation dans vos applications.

## Base URL

```
https://api-dev-auria-jask-sw-01.azurewebsites.net
```

## Authentification

Toutes les requêtes à l'API nécessitent une clé API passée dans le header `Authorization` :

```http
Authorization: Bearer YOUR_API_KEY
```

Vous pouvez obtenir votre clé API depuis votre tableau de bord Jask.

## Types de réponses

L'API Jask supporte deux types de réponses :

### 1. Réponses Streaming (SSE)

Pour les interactions conversationnelles en temps réel, l'API utilise Server-Sent Events (SSE). Les événements sont envoyés au format :

```
data: {"type": "streaming", "value": "texte..."}
```

### 2. Réponses Standard (JSON)

Pour les opérations non-conversationnelles, l'API retourne du JSON standard.

## Principaux endpoints

| Endpoint | Méthode | Description |
|----------|---------|-------------|
| `/ask/sse` | POST | Appeler un assistant en mode streaming |
| `/studio/apps/run` | POST | Exécuter une application/workflow |
| `/conversations/{id}` | POST | Créer/initialiser une conversation |

## Gestion des erreurs

Les erreurs sont retournées avec un code HTTP approprié et un message JSON :

```json
{
  "type": "error",
  "value": {
    "message": "Description de l'erreur",
    "code": "ERROR_CODE"
  }
}
```

### Codes d'erreur courants

| Code HTTP | Description |
|-----------|-------------|
| 400 | Requête invalide |
| 401 | Authentification manquante ou invalide |
| 404 | Ressource non trouvée |
| 500 | Erreur serveur interne |
