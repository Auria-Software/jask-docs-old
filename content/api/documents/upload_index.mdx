# Uploader et indexer un document

Cet endpoint combine l'upload et l'indexation : le fichier est stocké dans l'espace de travail puis indexé pour être utilisable en recherche (RAG) par un agent.

## Endpoint

```http
POST /documents/task/upload-and-index
```

## Headers requis

| Header          | Valeur                | Description        |
| --------------- | --------------------- | ------------------ |
| `Authorization` | `Bearer YOUR_API_KEY` | Clé API            |
| `Content-Type`  | `multipart/form-data` | Upload de fichiers |

## Corps de la requête

Requête `multipart/form-data` :

| Champ       | Type   | Requis | Description                                     |
| ----------- | ------ | ------ | ----------------------------------------------- |
| `files`     | file[] | ✅     | Un ou plusieurs fichiers à uploader             |
| `directory` | string | ✅     | Dossier de destination dans l'espace de travail |

<Callout type="info">
  Certains formats (Excel, Markdown, TXT, HTML, YAML) sont uploadés mais ignorés
  par l'indexation. Le champ `indexing.status` reste `true` avec `isTabular:
  true` le cas échéant.
</Callout>

## Réponse

Tableau JSON — un objet par fichier uploadé, avec le statut d'indexation.

```json
[
  {
    "name": "guide.pdf",
    "location": "workspace/documents/guide.pdf",
    "size": 245760,
    "isDir": false,
    "createdAt": "2025-06-30T10:30:00.000000",
    "principalId": "user-id",
    "principalName": "Jean Dupont",
    "indexing": {
      "status": true,
      "truncated": false,
      "isTabular": null,
      "totalRows": null
    }
  }
]
```

| Champ                | Type    | Description                                             |
| -------------------- | ------- | ------------------------------------------------------- |
| `location`           | string  | Chemin du fichier uploadé                               |
| `indexing.status`    | boolean | `true` si l'indexation a réussi (ou été ignorée)        |
| `indexing.truncated` | boolean | `true` si le contenu a été tronqué lors de l'indexation |

    ```python
import httpx

async def upload_and_index(file_path: str, api_key: str, directory: str = "workspace/documents") -> list:
async with httpx.AsyncClient(timeout=120) as client:
with open(file_path, "rb") as f:
response = await client.post(
f"https://{organization_jask_backend_name}.azurewebsites.net/api/v1/documents/task/upload-and-index",
headers={"Authorization": f"Bearer {api_key}"},
files={"files": (file_path.split("/")[-1], f)},
data={"directory": directory},
)
response.raise_for_status()
return response.json()

# Utilisation

result = await upload_and_index("./guide.pdf", "jask_api_key_abc123")
print(result[0]["location"], result[0]["indexing"])

````

  <Tabs.Tab value="JavaScript">
    ```javascript
async function uploadAndIndex(file, apiKey, directory = "workspace/documents") {
  const form = new FormData();
  form.append("files", file);
  form.append("directory", directory);

  const response = await fetch(
    "https://{organization_jask_backend_name}.azurewebsites.net/api/v1/documents/task/upload-and-index",
    {
      method: "POST",
      headers: { Authorization: `Bearer ${apiKey}` },
      body: form,
    }
  );

  if (!response.ok) throw new Error(`HTTP ${response.status}`);
  return response.json();
}

// Utilisation (navigateur)
const result = await uploadAndIndex(fileInput.files[0], "jask_api_key_abc123");
console.log(result[0].location, result[0].indexing);
````
