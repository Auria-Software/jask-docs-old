# Appeler un Agent en Streaming

Cet endpoint exécute le pipeline agent v2 et diffuse la réponse en temps réel via Server-Sent Events (SSE).

## Endpoint

```http
POST /assistant/ask/jask/v2
```

## Headers requis

| Header          | Valeur                | Description                   |
| --------------- | --------------------- | ----------------------------- |
| `Authorization` | `Bearer YOUR_API_KEY` | Clé API de l'agent à utiliser |
| `Content-Type`  | `application/json`    | Format du payload             |

## Corps de la requête

```typescript
{
  conversationId: string,  // ID unique de la conversation (UUID)
  query: string,           // Message de l'utilisateur
}
```

| Paramètre        | Type   | Requis | Description                                                                                                       |
| ---------------- | ------ | ------ | ----------------------------------------------------------------------------------------------------------------- |
| `conversationId` | string | ✅     | Identifiant de la conversation. Générez un UUID pour une nouvelle conversation — elle sera créée automatiquement. |
| `query`          | string | ✅     | Le message de l'utilisateur                                                                                       |

<Callout type="info">
  Aucune initialisation préalable de conversation n'est nécessaire. Réutilisez
  le même `conversationId` pour poursuivre un échange.
</Callout>

<Callout>
  Pour discuter d'un document avec l'agent, commencez par [uploader et indexer
  le fichier](/api/documents/upload_index). Une fois indexé, le contenu est
  disponible en recherche (RAG) — les sources apparaissent dans les événements
  `context` du stream.
</Callout>

## Réponse

Flux SSE (`text/event-stream`). Chaque événement est une ligne `data:` suivie d'un objet JSON.

### Événements principaux

| Type                  | Description                                   |
| --------------------- | --------------------------------------------- |
| `streaming`           | Fragment de texte de la réponse               |
| `context`             | Sources utilisées pour construire la réponse  |
| `conversationCreated` | Nouvelle conversation créée (contient l'`id`) |
| `end`                 | Fin du stream                                 |
| `error`               | Erreur pendant le traitement                  |

```
data: {"type": "streaming", "value": "La tour Eiffel "}
data: {"type": "streaming", "value": "mesure 330 mètres."}
data: {"type": "end", "value": {"status": true, "duration": 3.2}}
```

Des événements `ping` sont envoyés toutes les 5 secondes pour maintenir la connexion. Voir [Formats de Réponse](/api/formats) pour la liste complète des événements.

import httpx
import json
from uuid import uuid4

async def ask_agent_streaming(query: str, api_key: str, conversation_id: str = None) -> str:
conversation_id = conversation_id or str(uuid4())
full_response = ""

    async with httpx.AsyncClient() as client:
        async with client.stream(
            "POST",
            f"https://{organization_jask_backend_name}.azurewebsites.net/api/v1/assistant/ask/jask/v2",
            headers={
                "Authorization": f"Bearer {api_key}",
                "Content-Type": "application/json",
            },
            json={"conversationId": conversation_id, "query": query},
        ) as response:
            response.raise_for_status()
            async for line in response.aiter_lines():
                if not line.startswith("data:"):
                    continue
                try:
                    event = json.loads(line.removeprefix("data:").strip())
                    if event.get("type") == "streaming":
                        chunk = event.get("value", "")
                        full_response += chunk
                        print(chunk, end="", flush=True)
                    elif event.get("type") == "end":
                        break
                    elif event.get("type") == "error":
                        raise Exception(event.get("value"))
                except json.JSONDecodeError:
                    continue

    return full_response

# Utilisation

response = await ask_agent_streaming(
query="Quelle est la taille de la tour Eiffel ?",
api_key="jask_api_key_abc123",
)
print(f"\nRéponse complète: {response}")

````

    ```javascript
async function askAgentStreaming(query, apiKey, conversationId = crypto.randomUUID()) {
  const response = await fetch(
    'https://{organization_jask_backend_name}.azurewebsites.net/api/v1/assistant/ask/jask/v2',
    {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${apiKey}`,
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({ conversationId, query }),
    }
  );

  if (!response.ok) throw new Error(`HTTP ${response.status}`);

  const reader = response.body.getReader();
  const decoder = new TextDecoder();
  let fullResponse = '';

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;

    for (const line of decoder.decode(value).split('\n')) {
      if (!line.startsWith('data:')) continue;
      try {
        const event = JSON.parse(line.replace('data:', '').trim());
        if (event.type === 'streaming') {
          fullResponse += event.value;
          console.log(event.value);
        } else if (event.type === 'end') {
          return fullResponse;
        } else if (event.type === 'error') {
          throw new Error(event.value);
        }
      } catch (e) {
        if (e instanceof SyntaxError) continue;
        throw e;
      }
    }
  }

  return fullResponse;
}

// Utilisation
const response = await askAgentStreaming(
  "Quelle est la taille de la tour Eiffel ?",
  "jask_api_key_abc123"
);
console.log("Réponse:", response);
````
