# Formats de Réponse

L'API Jask supporte plusieurs formats de réponse selon le type d'endpoint appelé.

## Server-Sent Events (SSE)

Les endpoints streaming (`/ask/sse`, `/studio/apps/run`) utilisent le protocole SSE pour envoyer des événements en temps réel.

### Format général

```
data: {"type": "EVENT_TYPE", "value": ...}
```

Chaque ligne commence par `data:` suivi d'un objet JSON.

## Types d'événements - Assistants

### 1. `streaming`

Contient un fragment de la réponse de l'assistant.

```json
data: {"type": "streaming", "value": "Bonjour, "}
data: {"type": "streaming", "value": "comment "}
data: {"type": "streaming", "value": "puis-je vous aider ?"}
```

**Utilisation** : Assembler les fragments pour obtenir la réponse complète.

```python
full_response = ""
if event_type == "streaming":
    full_response += data.get("value", "")
```

### 2. `informative`

Fournit des informations contextuelles (résultats de recherche, métadonnées).

```json
data: {
  "type": "informative",
  "value": {
    "type": "searchResult",
    "value": {
      "resources": [
        {
          "id": "doc-123",
          "name": "Guide utilisateur",
          "webUrl": "https://...",
          "relevance": 0.95
        }
      ]
    }
  }
}
```

**Cas d'usage** : Afficher les sources utilisées par l'assistant.

### 3. `end`

Indique la fin du streaming.

```json
data: {"type": "end", "value": ""}
```

### 4. `error`

Signale une erreur pendant le traitement.

```json
data: {
  "type": "error",
  "value": {
    "message": "Timeout lors de la recherche",
    "code": "SEARCH_TIMEOUT"
  }
}
```

## Types d'événements - Applications

Les applications (workflows) envoient des événements spécifiques :

### 1. `taskStart`

Début d'une tâche dans le workflow.

```json
data: {
  "type": "taskStart",
  "value": {
    "taskId": "task-001",
    "taskName": "Document Generation"
  }
}
```



### 2. `taskEnd`

Fin d'une tâche.

```json
data: {
  "type": "taskEnd",
  "value": {
    "taskId": "task-001",
    "status": "success",
    "duration": 12.5
  }
}
```

### 3. `taskError`

Erreur dans une tâche.

```json
data: {
  "type": "taskError",
  "value": {
    "taskId": "task-001",
    "message": "Échec de génération du document"
  }
}
```

### `searchResult`

Résultats de recherche formatés.

```json
data: {
  "type": "searchResult",
  "value": [
    {
      "id": "doc-1",
      "name": "Documentation API",
      "url": "https://docs.example.com/api",
      "relevance": 0.92
    }
  ]
}
```

## Exemple complet: Parser les événements SSE

### Python avec httpx

```python
import httpx
import json

async def stream_assistant(payload: dict, api_key: str):
    full_response = ""
    documents = []
    
    async with httpx.AsyncClient() as client:
        async with client.stream(
            "POST",
            "https://api-dev-auria-jask-sw-01.azurewebsites.net/ask/sse",
            headers={
                "Authorization": f"Bearer {api_key}",
                "Content-Type": "application/json"
            },
            json=payload
        ) as response:
            async for line in response.aiter_lines():
                # Ignorer les lignes vides
                if not line.strip():
                    continue
                
                # Parser les lignes SSE
                if line.startswith("data:"):
                    try:
                        json_str = line.removeprefix("data:").strip()
                        data = json.loads(json_str)
                        event_type = data.get("type")
                        value = data.get("value")
                        
                        # Gérer les différents types d'événements
                        if event_type == "streaming":
                            full_response += value
                            print(value, end="", flush=True)
                        
                        elif event_type == "informative":
                            info = value.get("value", {})
                            if info.get("type") == "searchResult":
                                documents = info.get("resources", [])
                        
                        elif event_type == "error":
                            raise Exception(f"Error: {value}")
                        
                        elif event_type == "end":
                            print("\n[Stream terminé]")
                            break
                            
                    except json.JSONDecodeError:
                        continue
    
    return {
        "response": full_response,
        "documents": documents
    }
```

### JavaScript avec fetch

```javascript
async function streamAssistant(payload, apiKey) {
  const response = await fetch(
    'https://api-dev-auria-jask-sw-01.azurewebsites.net/ask/sse',
    {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${apiKey}`,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify(payload)
    }
  );

  const reader = response.body.getReader();
  const decoder = new TextDecoder();
  let fullResponse = '';

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;

    const chunk = decoder.decode(value);
    const lines = chunk.split('\n');

    for (const line of lines) {
      if (!line.startsWith('data:')) continue;

      try {
        const json = line.replace('data:', '').trim();
        const data = JSON.parse(json);

        switch (data.type) {
          case 'streaming':
            fullResponse += data.value;
            console.log(data.value);
            break;

          case 'informative':
            console.log('Info:', data.value);
            break;

          case 'end':
            console.log('Stream terminé');
            return fullResponse;

          case 'error':
            throw new Error(data.value.message);
        }
      } catch (e) {
        // Ignorer les erreurs de parsing
      }
    }
  }

  return fullResponse;
}
```
