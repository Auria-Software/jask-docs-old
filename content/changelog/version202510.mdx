# Jask 2025.10 : Nos Agents, Projets, Expériences...

Nous sommes ravis de vous dévoiler les fonctionnalités les plus demandées… prêtes à transformer votre expérience sur Jask 🚀

**Nouveaux cas d'usages désormais possibles :**

- Demandez aux agents d'effectuer des actions comme par exemple : "Enregistre ta réponse dans un fichier word dans le dossier Business de mon sharepoint Comex"
- Déployez un agent support IT/Metier personnalisé sur votre site public ou intranet, et utilisez Jask comme back-office pour créer des scénarios avec vos agents & applications.

## 🤖 Les Agents débarquent dans Jask !

Débloquez tout le potentiel agentique de Jask. Désormais, 3 catégories d'agents sont disponible sur la plateforme :

- Mode Default : Effectue des actions dans les différents outils qui lui sont configurés,
- Mode Super Agent : Délègue les questions aux agents qui lui sont connectés (ex : Un super agent exposé en interne pour le support auquel on rattache plusieurs agents spécialisés par domaine métier),
- Mode Deep Agent : Prépare un schéma de reflexion avant d'itérer sur toutes ses tâches afin de restituer des réponses d’une qualité sans précédent sur Jask.

## 💼 Collaborez dans notre module "Projets"

Testez ce nouvel espace de travail Projet dans Jask permettant de créer un environnement cloisonné pour vos projets.

Importez vos documents et profitez d’une Chatroom intégrée pour discuter directement avec vos documents. Lancez des applications directement depuis vos projets et invitez vos collègues à rejoindre l’espace de travail partagé pour collaborer sur les mêmes projets.

## 🎬 Facilitez l'Expérience dans Jask

Créez des expériences simplifiées pour accompagner vos utilisateurs finaux dans des parcours métiers prédéfinis.

Créez vos scénarios en quelques clics et partagez-les directement à vos équipes dans Jask, ou publiez-les sur vos sites internes et externes via API.

Vos utilisateurs n’ont plus à se soucier de quel agent ou application lancer ni quelles informations saisir : ils sont guidés pas-à-pas pour une expérience totalement fluide et transparente.

## ✨ Autres Nouveautés

- Les conversations de l'accueil sont désormais sauvegardées,
- Le menu de gauche a été repensé en plusieurs sections pour faciliter la navigation,
- La vue des catalogues (prompts system, agents, applications, expériences) a été uniformisée avec une barre de recherche et des sections personnalisables,
- Nouvelle action “Traduction de Document” dans la création d’application permettant de traduire un document Word et PPT en gardant le format initial du document,
- Des tutoriels vidéos sont accessibles depuis la page d'accueil,
- Nouvelle section dans le menu réglage “Extension IA” permettant de connecter des outils externes (en preview).
